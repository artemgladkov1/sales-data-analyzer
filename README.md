# Sales Data Analyzer

A Python-based data analysis project for processing sales data from CSV files and generating business-oriented metrics and reports.

## Project Status

🚧 **In development**

The project is being developed as part of a practical AI/ML engineering portfolio.

## Goals

The project is designed to demonstrate practical skills in:

* Python programming
* Data processing and validation
* Working with CSV files
* Business metrics and basic analytics
* Error handling and logging
* Automated testing with `pytest`
* Clean project structure and modular code

## Planned Features

* Import sales data from CSV files
* Validate input data
* Handle invalid records and data-quality issues
* Calculate key sales metrics
* Analyze revenue by customer and product
* Generate a summary report
* Add automated tests
* Improve the project with data analysis libraries as development progresses

## Tech Stack

* Python 3.14+
* Git / GitHub
* pytest
* Python standard library

## Installation

Clone the repository and create a virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Run the application:

```bash
python main.py
```
